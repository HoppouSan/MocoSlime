# Mocoslime

**Mocoslime** is an open-source bridge that connects **Sony mocopi** motion trackers to **SlimeVR** over **Bluetooth**.

The goal is to make it possible to use mocopi trackers as a wireless tracking solution within the SlimeVR ecosystem, without requiring the official mocopi software for the tracking pipeline.

# OS Support:
Windows: 10 & 11


## Features

* 🔵 Direct Bluetooth communication with mocopi trackers
* 🦴 SlimeVR-compatible tracking bridge
* 📡 Wireless motion tracking
* 🔄 Converts mocopi sensor data into SlimeVR-compatible data
* 💻 Designed for PC and VR applications
* 🛠️ Open-source and customizable
### Language Support

mocoSlime supports the following languages:

* EN English
* 🇩🇪 German
* 🇯🇵 Japanese
* 🇨🇳 Chinese

  

## Project Goal

mocoSlime aims to provide a simple and lightweight way to use **mocopi hardware with SlimeVR**, making it easier to integrate mocopi trackers into applications such as **VRChat** and other OpenXR/SteamVR environments.

## Status

🚧 **Early development**

Features, supported platforms, and tracker compatibility may change as development progresses.


### Tracking Connection

`Searching for Tracking...`

mocoSlime is searching for available mocopi trackers.

If no tracker is found or the connection is lost, mocoSlime will automatically attempt to reconnect:

`Searching for Tracking → Reconnecting → Connected`
