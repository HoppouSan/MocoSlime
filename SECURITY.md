# Security policy

Mocoslime is a Windows desktop application that communicates with nearby BLE
devices and sends tracking data to a configured SlimeVR server over UDP.

## Reporting a vulnerability

Do not post credentials, private diagnostics, or an exploitable vulnerability
in a public issue. Contact the maintainers through the private vulnerability
reporting channel configured for the repository. If no private channel is
available yet, ask a maintainer for a private contact before sending details.

Include the affected version, Windows version, impact, and a minimal
reproduction. Redact device identifiers and local network information unless
they are needed to explain the issue.

There is no published support window yet. Until a release policy is announced,
report issues against the latest available release.
